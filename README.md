# Банковский API на FastAPI

Простой и функциональный REST API для управления банковскими счетами. Проект написан на Python с использованием FastAPI, сохраняет данные в JSON и поддерживает комиссии, проценты и переводы.

---

## 🚀 Функционал

- ✅ Создание и удаление счетов
- ✅ Пополнение и снятие средств
- ✅ Переводы между счетами (с комиссией 1%)
- ✅ Начисление процентов на остаток (5%)
- ✅ История операций по каждому счёту
- ✅ Автоматическое сохранение данных в JSON
- ✅ Swagger-документация (автоматически)

---

## 🛠️ Технологии

- Python 3.9+
- FastAPI
- Uvicorn
- JSON (хранение данных)

---

## 📦 Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/твой-логин/bank_api.git

# Перейти в папку
cd bank_api

# Установить зависимости
pip install -r requirements.txt

# Запустить сервер
uvicorn bank_api:app --reload

После запуска открой в браузере: http://127.0.0.1:8000/docs
